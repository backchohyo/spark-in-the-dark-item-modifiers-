# Modifiers

Spark in the Dark 장비 모드입니다. 무기·갑옷·방패에 등급, 랜덤 추가 옵션, 유니크 특수 능력을 붙입니다.

[SparkModLoader](../SparkModLoader) 가 필요합니다.

## 설치

`release/Mods/Modifiers.dll` 을 게임 폴더의 `Mods` 폴더에 넣습니다. 기존 세이브 그대로 사용할 수 있습니다.

## 등급

장비를 처음 보거나 주울 때 등급이 정해지고 세이브에 저장됩니다. 이름 앞에 `[빛바랜]` `[은은한]` `[찬란한]`, 유니크는 `《이름》` 이 붙습니다.

| 등급 | 확률 | 기본 성능 | 추가 옵션 |
|---|---|---|---|
| 빛바랜 | 35% | -10% | 0~1개 |
| 은은한 | 45% | ±0 | 1~2개 |
| 찬란한 | 20% | +12% | 2~3개 |
| 유니크 | 5% (먼저 판정) | +12% | 2~3개 + 특수 능력 |

기본 성능은 무기 피해량, 양손무기 막기, 갑옷·방패 방어력에 곱해집니다. 석궁, 맨손, 부러진 무기, 뼈 무기, 램프, 반지·부적은 대상이 아닙니다.

## 추가 옵션 (19종)

장착 중일 때 적용됩니다. 등급이 높을수록 범위의 위쪽 수치가 나옵니다.

| 옵션 | 수치 | 붙는 장비 |
|---|---|---|
| 근력, 민첩성, 통찰력, 체질, 의지력 | +1 (찬란한은 25% 확률로 +2) | 전부 |
| 최대 스태미나 / 회복력 / 시야 | +5~12% / +6~15% / +4~10% | 전부 |
| 아이템 무게 | -10~25% | 전부 |
| 독 저항력, 어둠 저항력 | +8~20% | 전부 |
| 최대 체력, 회피율 | +4~10% | 갑옷·방패 |
| 최대 소지 무게 / 기동성 / 은신 / 방어력 | +6~15% / +2~5% / +5~12% / +4~10% | 갑옷 |
| 명중률 / 피해량 | +4~10% / +3~8% | 무기 |

## 유니크 (13종)

지니고 있는 유니크와 현재 층에 이미 나온 유니크는 다시 나오지 않습니다.

| 유니크 | 장비 | 능력 |
|---|---|---|
| 피의 갈증 | 무기 | 근접 피해의 10% 체력 흡수 |
| 처형인의 결의 | 무기 | 체력 30% 이하인 적에게 피해 +40% |
| 폭풍의 춤 | 무기 | 공격 스태미나 -35% |
| 영혼 수확자 | 무기 | 적 처치 시 체력 8%, 스태미나 25% 회복 |
| 광전사의 분노 | 무기 | 내 체력 50% 이하일 때 근접 피해 +25% |
| 질풍의 손놀림 | 무기 | 공격 속도 +15% |
| 불굴의 맹세 | 갑옷 | 내 체력 35% 이하일 때 받는 피해 -35% |
| 재생의 숨결 | 갑옷 | 매초 최대 체력 0.3% 회복 |
| 그림자 걸음 | 갑옷 | 은신 +25%, 회피율 +12% |
| 가시 방패 | 방패 | 막은 공격의 30% 반사 |
| 수호자의 맹세 | 방패 | 받는 피해 -12% |
| 별빛의 가호 | 공통 | 어둠 저항력 +35% |
| 해독의 축복 | 공통 | 독 저항력 +50% |

## 설정

게임 메인 메뉴 [모드] > Modifiers [설정]에서 적용 대상, 등급 비중, 등급별 옵션 개수, 옵션 19종의 사용 여부와 수치 범위, 유니크 등장 확률과 능력 수치를 바꿀 수 있습니다.

## 화면

- 아이템 설명 창 아래쪽에 등급, 옵션, 유니크 능력이 표시됩니다.
- 캐릭터 정보창(Tab)에는 장비 하나당 한 칸으로 옵션이 합쳐져 표시되고, 독·어둠 저항력은 능력치 표의 장비 무게 옆으로 옮겨집니다.

## 다른 모드와 연동

`Modifiers.Mod.ForceRoll(HandItem, 빛바랜비중, 은은한비중, 찬란한비중, 유니크확률)` 로 등급 확률을 지정해 바로 굴릴 수 있습니다. (MobModifiers 의 보상 장비에서 사용)

## 빌드

```
dotnet build -c Release
```

게임 폴더의 `Spark in the Dark_Data\Managed` 와 `Mods\ModLoader.dll` 을 참조합니다. 게임이 기본 경로가 아니면 `-p:GameDir="..."` 로 지정합니다.
